# MedService Frontend 🏥✨

Современный интерфейс аналитики отзывов и управления репутацией медицинских клиник.

Проект создан как основа для будущей платформы, которая позволяет:

- отслеживать отзывы пациентов  
- анализировать рейтинги и NPS  
- управлять запросами обратной связи  
- работать с филиалами в едином интерфейсе  

---

## 🚀 Технологии

Проект построен на современном стеке:

- **Next.js (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **Zustand (глобальное состояние)**
- **SVG Icons + кастомный UI layout**

---

## 📌 Основные разделы приложения

### 📊 Аналитика (`/analytics`)
Dashboard с KPI-карточками, графиками и выбором филиала через глобальный store.

---

### 💬 Отзывы и запросы (`/reviews-and-requests`)
Раздел для работы с отзывами и статусами:

- опубликованные отзывы  
- перехваченные жалобы  
- статусы запросов  

---

### ⚙ Настройки (`/settings`)
Заготовка под управление аккаунтом и конфигурацией системы.

---

## 🎨 Интерфейс

Приложение использует единый layout:

✅ Sidebar навигация  
✅ Header с выбором филиала  
✅ Страницы построены как модульная система под будущий backend

---

## 🗃 Zustand Store

Выбор филиала реализован через глобальное состояние:

- список филиалов  
- текущий выбранный филиал  
- синхронизация между страницами
